# Student Task Tracker

A responsive Student Task Tracker built using HTML, Tailwind CSS, and JavaScript.

## Features
- Add tasks with due dates
- Delete completed tasks
- Form validation
- Local Storage support
- Responsive design for mobile, tablet, and desktop

## Technologies Used
- HTML5
- Tailwind CSS
- JavaScript
- Local Storage
- Git & GitHub
